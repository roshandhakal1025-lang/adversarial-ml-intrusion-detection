# Adversarial Robustness of ML Intrusion Detectors

An educational research starter exploring constrained black-box evasion of machine-learning classifiers on **synthetic tabular data**.

This project is a starter and **does not reproduce the NSL-KDD results listed in a research resume**. It does not generate network attack traffic.

## Planned experiments
- Train logistic regression, random forest, gradient boosting, and multilayer perceptron classifiers.
- Evaluate clean accuracy and recall.
- Search for bounded feature changes under a 150-query budget.
- Measure evasion rates and test robustness improvements.

## Local setup
Use Python 3.10+ and install `numpy`, `pandas`, `scikit-learn`, and `pytest`. The full starter project is being added to this repository.

## Research integrity
Any numerical claims must be reproduced on documented datasets with recorded random seeds and evaluation protocols before being reported as findings.
